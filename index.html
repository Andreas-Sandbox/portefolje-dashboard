Ingen vedlikeholder denne siden. En GitHub Action kjører på timeplan og når issues endres: den henter prosjekt-feltene (team, kvartal, status) og avhengighetene via gh-CLI-et, regner ut tallene over, og publiserer siden på GitHub Pages. Samme data skrives også som et Mermaid-diagram inn i et fast «Avhengighetskart»-issue, som GitHub renderer direkte:

Issue / PR endres→ Action henter data→ data.json + Mermaid→ Pages + issue oppdateres 

    
Mermaid-blokken over er nøyaktig det som limes inn i et issue og vises som diagram på GitHub — null infrastruktur. Den interaktive grafen øverst er «nivå opp»: en statisk side på Pages som agenter og Copilot kan utvide videre, siden alt er kode.

  


  
POC · stiliserte eksempeldata, ikke ekte issues. Tall og team er funnet på for å vise formen på innsynet. Kjører helt frittstående — ingen nett eller innlogging.
